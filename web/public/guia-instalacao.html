Instale o Open Ads sem pular etapas.

Um roteiro para sair do zero até o painel aberto em localhost:4200, com comandos copiáveis, links oficiais e narração opcional do Fish Audio.

10 etapas · 45–60 min
Proteja suas credenciais. Nunca cole Client Secret, refresh token, chave de IA ou o JSON OAuth em chats, e-mails, capturas de tela ou GitHub. O comando npm run setup grava os dados diretamente no seu computador.

Ir para uma etapa

Antes de começar

Prepare o cenário.

Reserve entre 45 e 60 minutos. Use a mesma conta Google que já acessa o Google Ads e mantenha o projeto no seu próprio computador durante a configuração.

Você precisa de:
  • macOS, Windows 10/11 ou Linux;
  • acesso a uma conta do Google Ads;
  • acesso ao Google Cloud;
  • faturamento ativo no Google Cloud.
Não compartilhe:
  • arquivo JSON OAuth;
  • Client Secret ou refresh token;
  • conteúdo de server/.env.
Etapa 1

Instale o Node.js 22 LTS ou mais novo.

Acesse nodejs.org, baixe a versão LTS e conclua a instalação padrão. Depois abra Terminal no macOS/Linux ou PowerShell no Windows.

node -v

O resultado esperado começa com v22. ou uma versão superior. Se aparecer “comando não encontrado”, feche e abra o terminal novamente.

Etapa 2

Baixe o projeto e entre na pasta.

Descompacte o ZIP em uma pasta fácil de achar ou clone o repositório. No terminal, entre na pasta do projeto. Dica: digite cd , arraste a pasta para a janela e aperte Enter.

cd caminho/para/open-ads
Etapa 3

Instale as dependências.

Com o terminal dentro da pasta do projeto, rode o comando abaixo. Ele prepara a parte do servidor e a interface do painel.

npm run install:all

A operação pode levar alguns minutos. Avisos WARN podem aparecer; ela não deve terminar com ERR!.

Etapa 4

Crie um projeto no Google Cloud e ative a API.

  1. Abra o Google Cloud Console com a conta que acessa o Google Ads.
  2. Crie um projeto, por exemplo painel-ads, e confirme que ele ficou selecionado.
  3. Abra a página da Google Ads API e clique em Ativar.
  4. Na visão geral da API, solicite acesso Explorer quando o nível for Test.

O Google exige uma conta de faturamento ativa para liberar contas reais. O painel não cria cobranças no Google Cloud por conta própria.

Etapa 5

Configure a tela de consentimento OAuth.

  1. No Cloud, abra APIs e serviços → Tela de permissão OAuth ou Google Auth Platform.
  2. Preencha nome do app e e-mail de contato.
  3. Escolha público Externo e inclua seu e-mail em usuários de teste.
  4. Publique o app: o status deve ficar Em produção.

Publicar não torna o painel público. Isso evita que a autorização expire a cada sete dias.

Etapa 6

Crie o cliente OAuth sem expor o arquivo.

Em Credenciais → Criar credenciais → ID do cliente OAuth, escolha App para computador. Essa é a opção recomendada porque dispensa cadastrar URLs manualmente.

Se usar Aplicativo da Web, os redirecionamentos precisam ser exatamente:

http://localhost:8787/oauth2callback
http://127.0.0.1:8787/oauth2callback

Baixe o JSON e mantenha-o fora da pasta do projeto, por exemplo em Downloads. Ele contém um segredo.

Etapa 7

Use o assistente local de configuração.

npm run setup
  1. Quando o terminal pedir, arraste o JSON OAuth para ele e aperte Enter.
  2. Autorize a conta no navegador.
  3. Escolha a conta do Google Ads disponível.
  4. Ao terminar, rode o diagnóstico seguro.
npm run doctor

O diagnóstico confirma nomes de configurações e conectividade; ele não mostra os valores das chaves.

Etapa 8

Inicie e abra o painel.

npm start

Quando aparecer o endereço local, abra http://localhost:4200. Para parar, volte ao terminal e use Ctrl + C.

Segurança e suporte

Escolha o ambiente certo e resolva os erros comuns.

Recomendado: localhost

Na sua própria máquina, credenciais ficam no arquivo local ignorado pelo Git.

Rede ou internet

Na rede local, defina PANEL_ACCESS_TOKEN. Na internet, use também autenticação de borda, como Vercel Authentication, Cloudflare Access ou VPN.

Problemas recorrentes

  • redirect_uri_mismatch: confira as duas URLs da etapa 6.
  • invalid_grant: publique o app e execute npm run token.
  • SERVICE_DISABLED: ative a Google Ads API no projeto correto.
  • Porta 3000 em uso: feche a instância anterior do painel antes de iniciar outra.
