Bem-vindo ao OpenAds Desktop

O assistente oficial para instalar e configurar o OpenAds no seu computador com total segurança e sem precisar lidar com linhas de comando no terminal.

Ainda não criou o cliente no Google Cloud?

Vá em APIs e Serviços → Credenciais → Criar Credenciais → ID do cliente OAuth. Recomendado escolher "App para computador". Se escolher "Aplicativo da Web", configure a URL de redirecionamento para http://localhost:8787/oauth2callback.

📖 Guia Rápido de Instalação

O OpenAds foi projetado para rodar direto no seu computador. Para conectar à Google Ads API:

  1. Crie um projeto no Google Cloud Console: acesse console.cloud.google.com com o mesmo e-mail do Google Ads.
  2. Ative a Google Ads API: busque por "Google Ads API" na biblioteca e clique em Ativar.
  3. Configure o Consentimento: marque como "Externo", adicione seu e-mail como Usuário de Teste e clique em Publicar App.
  4. Crie a Credencial: crie um ID do cliente OAuth do tipo "App para computador" e baixe o arquivo JSON.
  5. Conecte no Wizard: arraste o JSON para o Passo 2 deste assistente e clique em Autorizar.
